# 断层回声 · Fault Line Echoes

一场发生在断层盆地的第一人称冒险。巡线员听见了本该沉寂的第三声闸响，沿着水路走访四境，寻找仍在下游生活的人。首页的「世界志」直接展示各境的实时三维场景。四个入口从初次启动起全部开放。

| 世界 | 主城 | 北门以外 |
| --- | --- | --- |
| 青雨林 | 汇流镇，水轮与听雨楼 | 穿过桫椤、蕉叶和喀斯特山壁，抵达听瀑石庭 |
| 白盐旱漠 | 白盐城，盐井与四风塔 | 越过旱季沙丘和古盐湖，找到风蚀的望潮天门 |
| 古根丛林 | 古根庭，树屋与菌架 | 沿着板根和古杉进入千年冠廊 |
| 断潮峡谷 | 断潮关，绞盘与矿轨 | 走向砂岩台地、石林与谷底河流 |

每张地图的可行走地形宽、深各 1,240 米。山脊在边界外延伸形成远景。地表、主城地下库窟和上层平台共用连续的碰撞空间。初访可从驿站向北出城，往东可找到地下坡道。

## 玩法

- 从叶岚、许砾、顾潮、陆衡中选择一人。行者空手出发，使用不同的位移、格挡、近战和远程技能。连击和格挡积蓄绝技回响。
- 走进主城可以和居民说话，向守卫邀请切磋。在野外会遇到主动戒备的生物。击中居民会引起受击者反击，目击的守卫也会介入。倒下后可以回到驿站。
- 主线共九章，另有十二条地方支线、三条隐秘分流线索和三个结局。手记可以追踪当前目标。奖励、装束、剧情选择和各世界的上次位置自动保存在当前浏览器。
- 昼夜连续运行。主城驿站可以休息到黎明或入夜。各境有自己的地表、环境声、天空和天气表现。

| 操作 | 键位 |
| --- | --- |
| 移动、观察 | WASD、鼠标。方向键也可转动视角 |
| 轻击、重击、格挡 | 鼠标左键、右键、按住 F |
| 技能、绝技 | Q / E / C、V |
| 疾跑、潜行 | 左 Shift、Z |
| 跳跃、攀树 | 空格、树干旁按住空格 |
| 交谈或调查、手记、暂停 | R、T、Esc |

## 本地运行与部署

使用 Node.js 22.12 或以上版本。

```sh
npm ci
npm run dev
```

`npm test` 验证地形、战斗、居民警戒和剧情分支。`npm run build` 生成生产资源到 `dist/`。`npm run preview` 可运行生产构建和本地房间接口。

在 Vercel 导入仓库根目录即可。仓库里的 `vercel.json` 配置了 Vite、安装与构建命令、产物目录和信令服务的运行区域。部署时无需配置游戏服务器密钥。单机游玩所需资源随站点提供，物理引擎在进入世界时加载。

### 双人联机

首页「联机」中一人创建房间，另一人输入六位房号。两端使用 WebRTC 数据通道，房主裁定命中、伤害与局分。比赛采用标准角色、可见装束和三局两胜制。

Vercel 的 `/api/rooms` 使用区域 Runtime Cache 临时交换连接描述，房号有效期三分钟。开发与本地预览使用同一接口和内存缓存。纯静态托管也可以用「手动直连」交换邀请和应答码。语音视频采集未启用。点对点连通性取决于两端的 NAT 和防火墙配置，项目没有自营 TURN 中继。

## 项目结构

| 文件 | 内容 |
| --- | --- |
| `src/biomes.js`、`src/landscape*.js` | 独立地貌、水系、林相、岩层和实景地标 |
| `src/settlement*.js`、`src/actors.js` | 主城建筑、地下与上层设施、居民、守卫及四种野怪的模型和动画 |
| `src/physics.js`、`src/combat.js`、`src/people.js` | Rapier 胶囊角色、移动与阻挡、自由瞄准、攻击和巡逻 |
| `src/story.js`、`src/journal.js` | 剧情、支线、结局、解锁及存档 |
| `src/view.js`、`src/sky.js`、`src/weather.js`、`src/audio.js` | Three.js 场景、实景天空、天气、环境声和第一人称视图 |
| `src/room.js`、`api/rooms.js`、`server/signaling.js` | 房间、信令和双人对战 |
