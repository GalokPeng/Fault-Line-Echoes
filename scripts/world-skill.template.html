Install in a project安装到游戏项目

          

            

              Unzip the download and place the entire build-game-world folder inside
              .agents/skills/ in your new project. Open that project in a new Codex chat and
              invoke $build-game-world.
            

            

              The archive includes the instructions, art intake example, system guides and reference
              build helper. You can extract it from this page while offline.
            

          

          

            

              下载并解压，将整个 build-game-world 文件夹放进新项目的
              .agents/skills/。用 Codex 在该项目新开对话，输入
              $build-game-world 即可调用。
            

            
压缩包内含 skill 说明、美术交付示例、技术指南和复现工具。断网打开本页也能提取。

            Attach the character GLB or effect files, a pose or timing reference, the role and action to

            effect events, integrate them, and return a playable comparison.
